# 华工数学 · 期末复习助手

> 一个给华南理工大学数学类专业本科生用的**期末专业课复习小助手**：上传讲义、课件、往年题，用你自己的 DeepSeek API Key，让 AI **只依据你的资料**答疑、出题、批改、整理错题。

纯前端单页应用（Vue 3 + Vite），没有服务器：资料、对话、错题本全部存在浏览器 IndexedDB 里，API Key 也只保存在本机。

---

## 功能

- **资料库**：拖拽上传 PDF / DOCX / PPTX / TXT / MD，本地解析成文本并切成检索块；支持粘贴文本、查看与手动修正解析结果、删除、按课程筛选。
- **资料检索**：本地 BM25 关键词检索（中文分词 + 二元组），每次提问只把最相关的片段发给模型，并生成【资料1】【资料2】引用编号。
- **对话复习**：流式回答、可折叠的思考过程（deepseek-reasoner）、引用可点开对照原文与页码、停止生成 / 重新生成、按会话保存。
- **出题练习**：按资料出单选 / 多选 / 判断 / 填空 / 计算 / 证明题，可选数量、难度、侧重点；生成结果经 JSON Schema 校验，不合法会要求模型自我修复一次。
- **作答与批改**：客观题本地判分（不耗额度），计算题与证明题由 AI 按"得分点 / 遗漏 / 错误 / 建议"批改。
- **错题本**：得分低于 60% 的题自动收录、同题去重、可标记已掌握；支持整本导出 Markdown。
- **导出与打印**：练习卷导出 Markdown，或直接打印成 A4 PDF（含答案与解析）。
- **课程预设**：数学分析、高等代数、解析几何、常微分方程、复变函数、实变函数、概率论与数理统计、抽象代数、微分几何、数值分析、偏微分方程、离散数学，可自定义。
- **演示模式**：没有 Key 也能跑通完整流程（回答与批改由本地脚本模拟，资料解析与检索是真实功能）。
- **数据管理**：一键导出 / 导入 JSON 数据包，换电脑继续复习；深色 / 浅色主题。

## 技术栈

| 方面 | 选择 |
| --- | --- |
| 框架 | Vue 3（`<script setup>`）+ Vite 7 + Pinia + Vue Router（hash 模式） |
| 解析 | `pdfjs-dist`（PDF）、`jszip` + 手写 XML 解析（DOCX / PPTX） |
| 检索 | 自写分词 + BM25 倒排索引，纯本地运行 |
| 渲染 | `markdown-it` + `katex`（自写公式插件与引用扩展） |
| 校验 | `zod`（题目 / 批改结果的结构化输出） |
| 存储 | IndexedDB（`idb`） |
| 测试 | Vitest + @vue/test-utils + jsdom |

不需要后端：DeepSeek 的接口允许浏览器直接跨域请求（带 `Authorization`），所以整个应用可以静态部署。

## 快速开始

环境要求：Node.js ≥ 20.19，pnpm ≥ 9。

```bash
pnpm install
pnpm dev          # 打开终端提示的地址（默认 http://localhost:5173）
```

构建与预览：

```bash
pnpm build        # 产物在 dist/
pnpm preview
```

> 如果 `pnpm install` 提示 `Ignored build scripts: esbuild`，执行一次 `pnpm approve-builds --all` 即可（仓库里的 `pnpm-workspace.yaml` 已声明允许 esbuild 运行安装脚本）。

## 使用流程

1. 打开「设置」，填入 [DeepSeek 开放平台](https://platform.deepseek.com) 的 API Key，点「测试连接」；没有 Key 可以先打开「演示模式」。
2. 到「资料库」上传这一学期的讲义、PPT、往年题（也可以直接粘贴文本）。
3. 到「对话复习」提问：
   - 「帮我梳理这一章的定理脉络，并标出条件。」
   - 「这道题不会，先给思路再给完整过程。」
   - 回答里的【资料n】可以点开看原文与页码。
4. 到「出题练习」选题型、数量、难度，生成一套卷子；做完提交批改。
5. 到「错题本」把丢分的题重做一遍，考前只看这里。

## API Key 与隐私

- Key 通过 `fetch` 直接发给你填写的接口地址（默认 `https://api.deepseek.com`），不经过任何中间服务器。
- 默认保存在浏览器 `localStorage`（明文）；公共电脑请选择「仅本次会话」（`sessionStorage`），用完点「清除」。
- 提问时只会发送：你的问题、对话历史、以及检索选中的资料片段（默认最多约 12000 字）。**不会**上传整份 PDF。
- 清除浏览器数据会连同资料、对话、错题本一起清空，建议定期用「设置 → 导出数据包」备份。

## 设计说明

- **为什么用 BM25 而不是向量检索**：DeepSeek 目前没有 embedding 接口；本地 BM25 不花钱、可解释、离线可用，配合 800 字小块与引用编号，已经能满足"按讲义答疑"的需求。
- **为什么纯前端**：不用部署后端与数据库，资料不出本机，换成静态托管即可分享给同学；代价是 Key 存在浏览器里，属于 BYOK 的固有风险。
- **出题为什么校验 JSON**：模型偶发会输出解释文字或漏字段；这里先用 `response_format: json_object`，再用 zod 校验，失败时带错误重试一次，仍失败则提示原始输出，不会白屏。
- **图表与公式**：PDF/PPT 由浏览器提取文字，公式可能错位；解析后可以在资料库手动修正，引用抽屉里也能看到原文片段。

## 已知限制

- 扫描版 PDF（图片）没有文字层，无法解析——请先 OCR 或改用「粘贴文本」。
- 公式以文本形式提取，复杂排版（分式、矩阵）可能丢结构；AI 回答里已提示"以资料为准"。
- 单文件上限 60MB；PDF 最多解析前 600 页；单次上下文预算默认 12000 字，可在设置里调整。
- 检索是关键词匹配，问法差异太大时可能找不到相关段落；这时回答会注明"资料中没有提到"。
- AI 生成的定义、答案、评分都可能出错，请以教材、老师课件与真题为准。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 401 / API Key 校验失败 | 到设置检查 Key 是否完整、是否被空格污染，点「测试连接」 |
| 402 / 余额不足 | 到 DeepSeek 平台充值 |
| 429 / 触发限流 | 等 10–30 秒；批量出题时不要连点 |
| 网络错误或跨域被拦截 | 检查代理；也可在设置里把接口地址换成为你提供服务的兼容地址 |
| 上传 PDF 提示没有文字 | 多半是扫描件，转成文字版或粘贴文本 |
| 回答没引用资料 | 资料库为空、或检索没命中；换更具体的问法，或在对话顶栏限定资料 |

## 部署

`pnpm build` 后把 `dist/` 丢到任意静态托管（GitHub Pages、Vercel、Nginx、学校服务器）即可。路由使用 hash 模式，不需要配置 history fallback；`vite.config.js` 里 `base: './'` 也支持子路径部署。
